## kNN法のデモ

### CSVの読み込み

```py
import pandas as pd
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split

df = pd.read_csv("my_data2.csv")
```
### 散布図

```py
import matplotlib.pyplot as plt

colors = {"A": "blue", "B": "orange"}
for species, group in df.groupby("species"):
    plt.scatter(group["width"], group["height"], label=species, c=colors[species])

plt.xlabel("width")
plt.ylabel("height")
plt.legend()
plt.title("width vs height (species)")
plt.savefig("scatter.png")
plt.show()
```

### 学習

```py
X = df[["width", "height"]]
y = df["species"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)

score = model.score(X_test, y_test)
print(f"テストデータの正答率: {score:.2f}")
```

### 推論

```py
new_samples = pd.DataFrame({"width": [3.70, 4.50], "height": [4.75, 4.60]})
pred = model.predict(new_samples)
print("予測結果:", pred)
```
