# 課題 - 分類

## 課題

* 以下の要件にしたがって、機械学習にチャレンジします。

|項目|説明|
|:--|:--|
|機械学習のタイプ|教師あり学習 - 分類|
|アルゴリズム|kNN（k近傍法）|
|データセット| my_data2.csv |

* my_data2.csvは、width, height, speciesの3項目で構成された100件のデータです。
* widthとheightの単位は同じものとします。
* speciesはAとBの2種類で、それぞれ50件ずつ含まれています。

|列名|説明|
|:--|:--|
|width|1つ目の特徴量|
|height|2つ目の特徴量|
|species|分類したい種別（A または B）|

---

## 手順

### 1. データの読み込み

* my_data2.csvを読み込んで、先頭5件と件数を確認します。

```py
import pandas as pd

df = pd.read_csv("my_data2.csv")
df.head()
```

### 2. 散布図で全体を確認する

* 学習の前に、AとBがどのように分布しているかを目で確認します。

```py
import matplotlib.pyplot as plt

colors = {"A": "blue", "B": "orange"}
for species, group in df.groupby("species"):
    plt.scatter(group["width"], group["height"], label=species, c=colors[species])

plt.xlabel("width")
plt.ylabel("height")
plt.legend()
plt.title("width vs height (species)")
plt.show()
```

> AとBはきれいに分かれていますか？　境界のあたりはどうなっているか、よく見てから次に進んでください。

### 3. 学習データとテストデータに分ける

* 特徴量（width, height）を`X`、正解ラベル（species）を`y`とします。
* 全体の30%をテストデータとして取り分けます。

```py
from sklearn.model_selection import train_test_split

X = df[["width", "height"]]
y = df["species"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0
)

print(len(X_train), len(X_test))
```

> 学習に使っていないデータで評価するために、あらかじめ分けておきます。

### 4. kNNで学習して正答率を確認する

* 最も近い3つのデータの多数決で分類します。

```py
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)

score = model.score(X_test, y_test)
print(f"テストデータの正答率: {score:.2f}")
```

### 5. 新しいデータを分類する

* 学習したモデルを使って、未知のデータがAとBのどちらかを予測します。

```py
new_samples = pd.DataFrame({"width": [3.70, 4.50], "height": [4.75, 4.60]})
pred = model.predict(new_samples)
print("予測結果:", pred)
```

### 6. 散布図で予測結果を確認する

* 学習データの散布図に、手順5の新しいデータ（赤い✕）を重ねて表示します。

```py
for species, group in X_train.assign(species=y_train).groupby("species"):
    plt.scatter(group["width"], group["height"], label=species, c=colors[species])

plt.scatter(new_samples["width"], new_samples["height"],
            c="red", marker="x", s=100, label="New Data")
plt.xlabel("width")
plt.ylabel("height")
plt.legend()
plt.title("width vs height (train data only)")
plt.show()
```

> 赤い✕の周りにあるデータの色と、手順5の予測結果は一致していますか？

---

## 発展課題

### 7. n_neighborsを変えて正答率を比較する

* `n_neighbors` を変えると、正答率がどう変わるかを調べます。

```py
scores = []
k_list = [1, 3, 5, 7, 9, 11, 15]
for k in k_list:
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, y_train)
    scores.append(model.score(X_test, y_test))

plt.plot(k_list, scores, marker="o")
plt.xlabel("n_neighbors")
plt.ylabel("score")
plt.title("n_neighbors vs score")
plt.show()
```

> `n_neighbors=1`のときの正答率は高いですか、低いですか。なぜそうなるのかを、手順2の散布図を見ながら考えてください。

### 8. 予測結果が変わることを確認する

* 手順5の新しいデータを、`n_neighbors`を変えて予測し直します。

```py
for k in [1, 3, 5, 7]:
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(X_train, y_train)
    print(f"n_neighbors={k}: {model.predict(new_samples)}")
```

> 同じデータなのに、予測結果が変わってしまうことがあります。
> なぜこのようなことが起きるのか、手順6の散布図から説明してみましょう。
