# 課題 - クラスタリング

## 課題

* 以下の要件にしたがって、機械学習にチャレンジします。

|項目|説明|
|:--|:--|
|機械学習のタイプ|教師なし学習 - クラスタリング|
|アルゴリズム|k-Means|
|データセット| my_clusters.csv |

* my_clusters.csvは、x, yの2項目で構成された500件のデータです。
* xとyの単位は同じものとします。

|列名|説明|
|:--|:--|
|x|1つ目の特徴量|
|y|2つ目の特徴量|

---

## 手順

### 1. データの読み込み

* my_clusters.csvを読み込んで、先頭5件と件数を確認します。

```py
import pandas as pd

df = pd.read_csv("my_clusters.csv")
df.head()
```

### 2. 散布図で全体を確認する

* クラスタリングの前に、データがどのように分布しているかを目で確認します。

```py
import matplotlib.pyplot as plt

plt.scatter(df["x"], df["y"])
plt.xlabel("x")
plt.ylabel("y")
plt.title("my_clusters")
plt.show()
```

> データはいくつのグループに分かれて見えますか？　散布図を見て予想を立ててから、次に進んでください。

### 3. k-Meansでクラスタリングする

* 手順2で予想したクラスター数で、k-Meansを実行します。

```py
from sklearn.cluster import KMeans

model = KMeans(n_clusters=3, n_init="auto", random_state=0)
model.fit(df)

labels = model.labels_
print(labels)
```

### 4. クラスタリングの結果を可視化する

* 各データを所属クラスターの色で塗り分けて、クラスター中心（`cluster_centers_`）も重ねて表示します。

```py
plt.scatter(df["x"], df["y"], c=labels)
plt.scatter(model.cluster_centers_[:, 0], model.cluster_centers_[:, 1],
            s=300, marker="X", c="red")
plt.xlabel("x")
plt.ylabel("y")
plt.title("k-Means (k=3)")
plt.show()
```

---

## 発展課題

### 5. クラスター数を変えて比較する

* `n_clusters`を2にした場合の結果も出力して、手順4と見比べます。
* k=2では、手順4で分かれていたどのクラスターが1つにまとめられましたか。
* まとめられた2つのクラスターには、どのような関係があると言えますか。

### 6. エルボー法で最適なクラスター数を調べる

* クラスター数を1から10まで変化させ、SSE（`inertia_`）の変化をグラフにします。

```py
sse = []
for k in range(1, 11):
    model = KMeans(n_clusters=k, n_init="auto", random_state=0)
    model.fit(df)
    sse.append(model.inertia_)

plt.plot(range(1, 11), sse, marker="o")
plt.xlabel("k")
plt.ylabel("SSE")
plt.title("Elbow Method")
plt.show()
```

> グラフの「肘（ひじ）」に見える位置が、目安となるクラスター数です。

* このグラフはk=1のSSEが大きすぎて、それ以降の変化が読み取りにくくなっています。
* k=2から10までの範囲だけを描き直して、もう一度「肘」の位置を確認してください。

```py
plt.plot(range(2, 11), sse[1:], marker="o")
plt.xlabel("k")
plt.ylabel("SSE")
plt.title("Elbow Method (k >= 2)")
plt.show()
```

> グラフの見せ方によって「肘」の位置の印象が変わることを確認しましょう。
