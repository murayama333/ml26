# 演習：外れ値と考察

## データについて

`study_score.csv` は、ある学校の生徒50人の「1週間の勉強時間」と「テストの点数」のデータです。

study_score.csv

| 列名 | 内容 |
|---|---|
| student_id | 生徒の番号（1〜50） |
| study_hours | 1週間の勉強時間（時間） |
| score | テストの点数（0〜100点） |

このデータには、いくつかの「気になるデータ」が含まれています。
いろいろな方法で外れ値を探し、それぞれの方法で**何が見つかり、何が見つからないか**を確かめましょう。

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("study_score.csv")
```

---

## 問題1：まずデータを眺める

1. `df.describe()` を実行し、`study_hours` と `score` の最小値・最大値を確認してください。
2. 明らかにおかしいと思われる値はありますか？ どの生徒の、どの値ですか？

## 問題2：箱ひげ図で確認する

1. `study_hours` と `score` の箱ひげ図を、列ごとに分けて描いてください。
2. 外れ値（○）として表示されている点はいくつありますか？

## 問題3：IQR法で外れ値を検出する

1. `study_hours` と `score` のそれぞれについて、Q1、Q3、IQRを計算してください。
2. 「Q1 − 1.5 × IQR より小さい、または Q3 + 1.5 × IQR より大きい」値を外れ値として、該当する生徒の `student_id` を列挙してください。

## 問題4：Zスコアで外れ値を検出する

1. `study_hours` と `score` のそれぞれについてZスコアを計算し、|Z| > 3 となる生徒の `student_id` を列挙してください。
2. 問題3（IQR法）の結果と比べて、違いはありますか？
3. 違いがある場合、なぜそうなったのか考えてください。
   （ヒント：Zスコアは平均と標準偏差を使います。極端な値があると、平均と標準偏差はどうなるでしょうか？）

## 問題5：入力ミスを修正して再計算する

調べた結果、次の2つは入力ミスだとわかりました。

- student_id 12 の点数：正しくは **72点**
- student_id 25 の勉強時間：正しくは **15時間**

1. この2つを修正したデータフレーム `df_fixed` を作成してください（元の `df` は変更しないこと）。
2. `df_fixed` で、`study_hours` のZスコアを計算し直してください。問題4の結果から何が変わりましたか？

## 問題6：散布図で確認する

1. `df_fixed` で、横軸を `study_hours`、縦軸を `score` とした散布図を描いてください。
2. 全体の傾向から外れているように見える点はありますか？
3. その点は、問題3や問題4の方法で検出できましたか？ 検出できなかった場合、その理由を説明してください。

## 問題7：回帰の残差で外れ値を検出する

1. `df_fixed` で、`study_hours` から `score` を予測する線形回帰モデルを作成してください。
2. 各生徒の残差（実際の点数 − 予測値）を計算し、残差を標準偏差で割った値（標準化残差）の絶対値が2を超える生徒を列挙してください。
3. 問題6で「外れているように見えた点」と一致しましたか？

## 問題8：外れ値をどう扱うか考える

1. それぞれの外れ値には、どんな原因が考えられますか？
2. 分析から**除外すべきもの**と、**残すべきもの**はどれですか？ 理由も答えてください。
