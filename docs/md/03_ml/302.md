# 演習：BMIから糖尿病の進行度を予測する（単回帰）

## データセットの説明

この演習では、scikit-learn に付属している **糖尿病データセット（`load_diabetes`）** を使います。

糖尿病患者 **442人** について、ある時点（ベースライン）で測定した10個の項目と、**その1年後の病状の進行度** が記録されています。インターネットからのダウンロードは不要で、scikit-learn をインストールしていればすぐに読み込めます。

### 特徴量（説明変数）

| 列名 | 意味 |
|---|---|
| `age` | 年齢（歳） |
| `sex` | 性別（1 または 2） |
| `bmi` | BMI（体格指数） |
| `bp` | 平均血圧 |
| `s1` | 血清総コレステロール |
| `s2` | LDLコレステロール |
| `s3` | HDLコレステロール |
| `s4` | 総コレステロール／HDL比 |
| `s5` | 血清トリグリセリド値の対数（とされている値） |
| `s6` | 血糖値 |

### 目的変数

| 列名 | 意味 |
|---|---|
| `target` | ベースラインから1年後の病状の進行度（数値が大きいほど進行している。おおよそ25〜346の範囲） |

### BMIについて

BMI（Body Mass Index）は、身長と体重から肥満の度合いを表す指標で、次の式で計算します。

```
BMI = 体重(kg) / 身長(m)^2
```

日本では 18.5以上25未満が「普通体重」、25以上が「肥満」とされています。肥満は糖尿病の大きなリスク要因であることが知られています。

### 読み込み方

このデータセットは、通常の読み込み方では各列が **標準化された値（平均0付近の小さな小数）** になっています。この演習では、BMIを実際の値（22.5 など）のまま扱いたいので、`scaled=False` を指定して読み込みます。

```python
from sklearn.datasets import load_diabetes

data = load_diabetes(as_frame=True, scaled=False)
df = data.frame   # 特徴量10列＋target列の DataFrame
```
