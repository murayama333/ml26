# 決定係数

- 決定係数 $R^2$ は、目的変数の全変動のうち回帰で説明できる割合を表す指標
- 全変動 $S_{yy}=\sum_i (y_i-\bar{y})^2$ と残差平方和 $S_e=\sum_i (y_i-\hat{y}_i)^2$ を用いて $R^2 = 1 - S_e/S_{yy}$ と定義する
- 説明変数を増やすと $R^2$ は必ず増えるため、自由度で補正した自由度調整済み決定係数を併用する

```py
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("score.csv")

X = df[["math"]]
y = df["science"]

model = LinearRegression()
model.fit(X, y)

print("決定係数 R²:", model.score(X, y))
print("傾き:", model.coef_[0])
print("切片:", model.intercept_)
```


```py
# yの分散
y_var = y.var(ddof=0)
y_var
```

```py
# yの予測値の分散
y_pred = model.predict(X)
y_pred_var = y_pred.var(ddof=0)
y_pred_var
```

```py
# 残差
residuals = y - y_pred

# 残差の分散
residuals_var = residuals.var(ddof=0)
residuals_var
```

```py
# 決定係数
1 - residuals_var / y_var
# y_pred_var / y_var
```
