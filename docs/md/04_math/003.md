# 文字定数を含む式の微分

## この節でわかること

+ $c$ のような文字が入っていても微分できる
+ どの文字で微分するのかを意識できる
+ 定数として扱う文字と、変数として扱う文字を見分けられる

## ここまでの流れ

+ 3つのルールで多項式を微分できるようになった
+ 連鎖律でかっこのついた式を微分できるようになった
+ ここまで、式に出てくる文字は $x$ だけだった

> 💬 ここからは、文字が2種類出てくる式を扱います。

## 考えてみよう

+ $y = (c - x)^2$ を微分したい
+ $c$ は、具体的な数がまだ決まっていない文字
+ このまま前の節と同じように進めてよいのか、迷うところ

> 💬 迷ったら $c$ に $5$ を入れてみてください。前の節の例3そのものです。

## 文字定数とは

![左に「動く文字 x」、右に「動かない文字 c」と書かれ、c には数と同じ扱いを表す札がついている図](https://jittoku.jittoku.workers.dev/api/md/sanrjazm22/files/haksqsrpgd)

+ 値は決まっていないが、いまは動かさない文字がある
+ このような文字を**文字定数**という
+ 微分するときは、$5$ や $-2$ といった数とまったく同じに扱う

> 💡 「文字だから難しい」のではありません。数の代わりに置いてあるだけです。

## どの文字で微分するのかを決める

+ 文字が2種類あると、$y'$ と書いただけでは何をしたのか伝わらない
+ そこで「$x$ で微分する」と決めて、はっきり書く
+ $\frac{dy}{dx}$ の下にある $x$ が、その「$x$ で微分する」を表している

> 💬 この節ではすべて $x$ で微分します。$c$ は動かしません。

## 定数は2通りの現れ方をする

+ 係数としての定数は、そのまま残る
+ 項としての定数は、微分すると $0$ になって消える
+ $c\,x^2$ の $c$ は残り、$x^2 + c$ の $c$ は消える

> ⚠️ 同じ $c$ でも、式のどこにいるかで結果が変わります。

## 例1 係数としての文字定数

> 💬 $y = c\,x^2$ を $x$ で微分しましょう。

+ $c$ は数と同じなので、係数として外に置く
+ $x^2$ を微分して $2x$
+ $c$ をかけ戻して $\frac{dy}{dx} = 2cx$

## 例2 項としての文字定数

> 💬 $y = x^2 + c$ を $x$ で微分しましょう。

+ $x^2$ を微分して $2x$
+ $c$ は定数の項なので $0$
+ 並べ直して $\frac{dy}{dx} = 2x$

> 💡 $c$ が消えるのは、$c$ が $x$ の動きに関係しないからです。

## 例3 かっこと文字定数

> 💬 $y = (c - x)^2$ を $x$ で微分しましょう。

+ 外側を微分して $2(c - x)$
+ 内側を微分して $(c - x)' = 0 - 1 = -1$
+ かけあわせて $\frac{dy}{dx} = -2(c - x)$

> 💡 $c = 5$ とすると $-2(5 - x)$。01-02 の例3と一致します。

## 検算のしかた

+ 文字定数に、好きな数を1つ入れてみる
+ その式を微分し、さきほどの答えに同じ数を入れる
+ 両方が一致すれば、まず正しい

> 💡 文字のままだと不安なときは、いつでもこの手が使えます。

## 気をつけること

+ 係数の定数は残り、項の定数は $0$ になる
+ 内側の $-x$ から出るマイナスを落とさない
+ どの文字で微分しているのかを、毎回はっきりさせる

> ⚠️ $c$ を変数と思って $c' = 1$ としないこと。$c$ の微分は $0$ です。

## まとめ

+ 値が決まっていなくても、動かさない文字は**文字定数**として数と同じに扱う
+ **係数の定数は残り、項の定数は $0$ になって消える**
+ 文字が2種類あるときは、$\frac{dy}{dx}$ のように**どの文字で微分するか**を書く
+ $y = (c - x)^2$ を $x$ で微分すると $-2(c - x)$
+ 文字定数に数を入れれば、いつでも検算できる
