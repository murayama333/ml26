# べき乗・定数倍・和の微分

## この節でわかること

+ 微分が何をする操作なのかがわかる
+ べき乗・定数倍・和差の3つのルールを使い分けられる
+ $y = 3x^2 - 4x + 5$ のような式を微分できる

## ここまでの流れ

+ 線形回帰では、データとのズレが最小になる直線を探す
+ ズレの大きさは、直線の傾きと切片を変えると上下する
+ これをグラフにすると谷の形になり、いちばん低い点が答えになる

> 💬 その谷底を式で探す道具が微分です。ここから始めます。

## 考えてみよう

+ $y = 3x^2 - 4x + 5$ のグラフを、左から右へ歩いていくと想像する
+ 最初は下り坂、やがて平らな底を通り、そのあとは上り坂になる
+ 同じグラフでも、場所によって傾きがちがう

> 💬 「いま立っている場所の傾き」は、どうすれば数値で言えるでしょうか。

![左が下り坂、真ん中が平ら、右が上り坂になっている放物線](https://jittoku.jittoku.workers.dev/api/md/cpc9tj9mu8/files/43jsnhdxbd)

## 微分とは

+ **ある式から、その点での傾きを表す式をつくる操作**
+ できあがった傾きの式を**導関数**という
+ 書き方は $y'$ または $\frac{dy}{dx}$
+ 導関数に $x$ の値を代入すると、その場所の傾きが数値で出る

> 💬 グラフのその点に引いた接線のかたむき、と考えてください。

## ルール1 べき乗の微分

+ **肩の数字を前に降ろして、肩を1つ減らす**
+ $x^2$ を微分すると $2x$
+ $x^3$ を微分すると $3x^2$
+ 一般には $(x^n)' = n \, x^{n-1}$

## ルール2 定数倍はそのまま残る

+ **係数は微分に関係しない。そのまま残る**
+ $3x^2$ なら、$x^2$ の微分 $2x$ に $3$ をかけて $6x$
+ 一般には $(c \, f(x))' = c \, f'(x)$

## ルール3 和と差は項ごとに分けられる

+ **足し算・引き算でつながった式は、1項ずつ独立に微分できる**
+ 長い式でも、バラして微分し、また並べ直せばよい
+ 一般には $(f + g)' = f' + g'$

> 💡 この3つだけで、多項式はすべて微分できます。

## 例1 べき乗と定数倍

> 💬 $y = 5x^2$ を微分しましょう。

+ 係数の $5$ はいったん外に置く
+ $x^2$ の微分は $2x$
+ これに $5$ をかけて $y' = 10x$

## 例2 項ごとに分ける

> 💬 $y = 3x^2 - 4x + 5$ を微分しましょう。

+ $3x^2$ は、肩の $2$ を降ろして $2 \times 3 = 6$、肩は $1$ になり $6x$
+ $-4x$ は、$x = x^1$ なので肩の $1$ を降ろし、肩は $0$。$x^0 = 1$ が残り $-4$
+ $+5$ は定数なので $0$ になって消える
+ 並べ直して $y' = 6x - 4$

> 💡 項を縦に並べて書き、1つずつ処理すると取りこぼしません。

## 導関数が $0$ になる場所

+ 例2で求めた $y' = 6x - 4$ に値を入れてみる
+ $x = 0$ のとき $y' = -4$ で下り坂
+ $x = 1$ のとき $y' = 2$ で上り坂
+ $x = \frac{2}{3}$ のとき $y' = 0$ で平ら

> 💬 傾きが $0$ の場所が、グラフの谷底です。

## 例3 谷底を求める

> 💬 $y = 3x^2 - 4x + 5$ が最小になる $x$ を求めましょう。

+ 導関数は $y' = 6x - 4$
+ これを $0$ とおいて $6x - 4 = 0$
+ 解いて $x = \frac{2}{3}$

> 💡 **微分して $0$ とおく**。この手順が、線形回帰でやることそのものです。

## 気をつけること

+ $-4x$ は「$x$ が消える」のではなく、$x^0 = 1$ が残って係数だけになる
+ 定数が消えるのは、上下に平行移動しても形が変わらないから
+ 係数と肩の数字を取りちがえない

> ⚠️ $3x^2$ の微分を $3x$ としないこと。肩の $2$ をかけて $6x$ です。

## まとめ

+ 微分は、もとの式から **傾きの式（導関数）** をつくる操作
+ **べき乗は、肩を前に降ろして肩を1つ減らす**
+ 係数はそのまま残り、定数は $0$ になって消える
+ 和と差は、項ごとに分けて微分できる
+ **導関数が $0$ になる場所が、グラフの谷底**
