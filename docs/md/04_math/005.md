# 偏微分 ― 動かす文字を1つに絞る

## この節でわかること

+ 文字が2つある式を微分できる
+ 偏微分の記号 $\partial$ の読み方と意味がわかる
+ $f(a, b) = \bigl(5 - (2a + b)\bigr)^2$ を $a$、$b$ それぞれで偏微分できる

## ここまでの流れ

+ 動かす文字は自分で決めるものだと分かった
+ ただし、そこで動かす文字は1つだけだった
+ 線形回帰では、傾き $a$ と切片 $b$ の2つを決めたい

> 💬 動かしたい文字が2つあるときを考えます。

## 考えてみよう

+ $f(a, b) = \bigl(5 - (2a + b)\bigr)^2$ という式がある
+ 文字が2つあるので、グラフは谷ではなくすり鉢のような形になる
+ $a$ と $b$ を同時に動かすと、手に負えない

> 💬 そこで、片方を止めて1つずつ動かします。

## 偏微分とは

![動かす文字aの箱、いまは止めている文字bの箱、動かない数5と2の箱が横に3つ並んでいる図](https://jittoku.jittoku.workers.dev/api/md/79qw6xm33t/files/k9b9ri8f7j)

+ **ほかの文字を止めて、1つの文字だけで微分すること**を偏微分という
+ 記号は $\partial$（ラウンドディー）を使う
+ $\frac{\partial f}{\partial a}$ は「$b$ を止めて、$a$ で微分する」と読む

> 💡 やることは増えません。止めた文字は、ただの数と同じ扱いです。

## 記号の使い分け

+ 動く文字が1つのときは $\frac{dy}{dx}$
+ 動かせる文字が2つ以上あるときは $\frac{\partial f}{\partial a}$
+ 形がちがうだけで、計算の手順は変わらない

> 💬 $d$ が $\partial$ に変わったら「ほかにも動かせる文字がある」の合図です。

## 止めることと、消すことはちがう

+ $a$ で偏微分するとき、$b$ は止まっている
+ 止まっている $b$ は、$5$ や $2$ と同じ扱い
+ 定数の項として現れれば $0$ になるが、$b$ 自体が消えるわけではない

> ⚠️ $b$ を $0$ に置きかえてはいけません。止めるのと消すのは別です。

## 例1 $a$ で偏微分する

> 💬 $f(a, b) = \bigl(5 - (2a + b)\bigr)^2$ を $a$ で偏微分しましょう。

+ 外側を微分して $2\bigl(5 - (2a + b)\bigr)$
+ 内側を $a$ で微分する。$5$ と $b$ は定数なので $0$
+ 残るのは $-2a$ の部分で、内側の微分は $-2$
+ かけあわせて $\frac{\partial f}{\partial a} = -4\bigl(5 - (2a + b)\bigr)$

## 例2 $b$ で偏微分する

> 💬 同じ式を、こんどは $b$ で偏微分しましょう。

+ 外側は例1とまったく同じで $2\bigl(5 - (2a + b)\bigr)$
+ 内側を $b$ で微分する。$5$ と $2a$ は定数なので $0$
+ 残るのは $-b$ の部分で、内側の微分は $-1$
+ かけあわせて $\frac{\partial f}{\partial b} = -2\bigl(5 - (2a + b)\bigr)$

> 💡 外側は共通です。ちがうのは内側の微分だけでした。

## 2つの答えを見くらべる

+ $a$ のときは $-4$、$b$ のときは $-2$ が前に出た
+ ちがいを生んだのは、内側で $a$ についていた係数 $2$
+ $b$ の係数は $1$ なので、そのまま出てきた

> 💬 内側にいる文字の係数が、そのまま結果に効いてきます。

## すり鉢の底を探す

+ 底では、どちらの向きに動かしても傾きが $0$ になる
+ つまり $\frac{\partial f}{\partial a} = 0$ と $\frac{\partial f}{\partial b} = 0$ を同時に満たす点
+ 式が2本できるので、連立して解く

> 💬 これが線形回帰の最後の一手です。あと一歩まで来ました。

## 気をつけること

+ 止めた文字は数と同じ扱い。$0$ に置きかえない
+ 外側の微分は共通で、変わるのは内側だけ
+ $d$ と $\partial$ を書き分ける

> ⚠️ $\frac{\partial f}{\partial a}$ と $\frac{\partial f}{\partial b}$ で答えがちがうのは当然です。同じになったら計算を疑ってください。

## まとめ

+ **ほかの文字を止めて、1つの文字だけで微分すること**を偏微分という
+ 記号は $\frac{\partial f}{\partial a}$。分母の文字が、動かす文字
+ 止めた文字は、数とまったく同じに扱う
+ 外側の微分は共通で、$a$ か $b$ かで変わるのは内側の微分
+ すり鉢の底は、**2つの偏微分がどちらも $0$ になる点**
